## 🚀 Live GitHub Pages URLs

Once GitHub Pages is enabled on this repository, your pages will be available at:

- **Legal Hub:** `https://jumperk12.github.io/FrontRow-AI/`
- **Privacy Policy:** `https://jumperk12.github.io/FrontRow-AI/privacy.html`
- **Terms & Conditions:** `https://jumperk12.github.io/FrontRow-AI/terms.html`
- **Content Consent & Anti-NSFW:** `https://jumperk12.github.io/FrontRow-AI/content-policy.html`

### How to Enable GitHub Pages (1-Minute Setup):
1. Go to your GitHub repository: [https://github.com/Jumperk12/FrontRow-AI](https://github.com/Jumperk12/FrontRow-AI)
2. Click **Settings** (top right tab).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment** &rarr; **Source**, select **Deploy from a branch**.
5. Under **Branch**, select **`main`** and **`/ (root)`**, then click **Save**.
6. In ~60 seconds, GitHub Pages will publish your live website!
